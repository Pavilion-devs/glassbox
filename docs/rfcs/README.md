# Metadata RFC drafts

These documents are maintainer-facing proposals backed by working GlassBox evidence.
They are not claimed as submitted, accepted, or implemented in DataHub Core.

| Draft | Status | Scope |
| --- | --- | --- |
| [Agent decision receipts and runtime influence](000-agent-decision-receipts-and-runtime-influence.md) | Pre-RFC discussion | Native consequential-output entity, qualified influence, integrity, invalidation, and supersession |

The draft intentionally extends, rather than forks,
[DataHub Agent Registry RFC #16012](https://github.com/datahub-project/datahub/pull/16012).
Its unresolved naming and identity questions should be settled with maintainers before
an RFC pull request is opened.
